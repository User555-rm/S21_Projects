Java-игра Roguelike: процедурная генерация подземелий и пошаговый геймплей (командный):
- Построил на многослойной архитектуре (domain / presentation / data) с инверсией зависимостей — игровая логика изолирована от UI и хранилища; 74 класса / ~11,6 тыс. строк, Maven, Java 21, UI на Lanterna 3.1.2, JSON на Gson.
- Реализовал процедурную генерацию 21 уровня (9 комнат + связные коридоры, регенерация при невалидной раскладке), пошаговый цикл «ход игрока → ход монстров», боевую систему на формулах ловкости/силы, 4 категории предметов (еда, эликсиры, свитки, оружие, сокровища).
- Написал ИИ 6 типов монстров с уникальными паттернами: преследование по дистанции враждебности; вампир (первый удар — промах, крадёт макс. HP), призрак (телепорт/невидимость), огр (шаг на 2 клетки и отдых), змей-маг (диагональ + усыпление), мимик (маскировка под предмет).
- Реализовал туман войны (Ray Casting + Брезенхэм, радиус 12): состояния «неизведанно / посещено / видимо», отрисовка комнат и коридоров, переключение клавишей `f`.
- Реализовал цветные ключи и двери (5 цветов, как в DOOM) с BFS-валидацией достижимости и отсутствия софтлоков — при неудаче уровень перегенерируется автоматически.
- Внедрил адаптивный баланс сложности: метрики игрока (урон, попадания, лечение, убийства) в скользящем окне последних уровней → автоподстройка количества/силы врагов и полезных предметов.
- Обеспечил персистентность: Gson-сериализация всей сессии (DTO + маппер, позиции всех сущностей, характеристики, инвентарь, эффекты), сохранение после каждого уровня, статистика попыток и таблица рекордов; код-качество — Spotless (Google Java Format) + Checkstyle, командная работа в ветке develop.
