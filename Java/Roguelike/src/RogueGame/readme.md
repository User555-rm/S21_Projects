### Запуск за линукс
1. Перейти в корень проекта (там pom.xml, скрипты запуска)
2. Выдать права maven
```
chmod +x mvnw
```
3. Выполнить команду запуска скрипта в терминале
```
./run.sh
```

### Запуск на винде (не открывает swing, сразу идет в консоль, надо чинить)
1. Перейти в корень проекта (там pom.xml, скрипты запуска)
2. Выполнить команду запуска скрипта в консоли или дважды щелкнуть по скрипту
```
run.bat
```

### Ремарка

Если возникает проблема с maven командами, нужно:
1. Зайти на https://maven.apache.org/download.cgi
2. Скачать Binary zip archive	apache-maven-3.9.14-bin.zip
3. Распаковать архив в любую папку без русских символов
4. Добавить его в переменные среды Path (win + r -> sysdm.cpl -> переменные среды -> Path -> добавить путь к папке bin, которая лежит в разархивированной папке)
5. Перезагрузить терминал
6. Запустить скрипт

Если возникнет проблема с jdk на линукс:
```
sudo apt install openjdk-21-jdk
```

При запуске на винде swing используется как fallback.
