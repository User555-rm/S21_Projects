SimpleNavigator — библиотека и консольное приложение алгоритмов на графах (Java, командная разработка): 
- Разработал на Java 17 библиотеку s21_graph + s21_graph_algorithms и консольное приложение (~1100 строк кода): модель графа на матрице смежности с загрузкой из файла, валидацией формата входных данных (размер матрицы, неотрицательные веса, связность — включая слабую связность орграфов) и экспортом в DOT-формат для визуализации в Graphviz (взвешенные/ориентированные графы, петли). 
- Реализовал классические графовые алгоритмы: поиск в глубину и ширину (нерекурсивные), Дейкстра, Флойд–Уоршелл, Прим (минимальное остовное дерево) и муравьиный алгоритм (ACO) для задачи коммивояжёра с вероятностным выбором маршрута, испарением феромона и ранней остановкой. 
- Написал собственные обобщённые структуры данных Stack<T> и Queue<T> на динамическом массиве (очередь — с кольцевым буфером), используемые алгоритмами обхода. 
- Покрыл код 100 модульными тестами JUnit 5 (24 — модель графа, 76 — алгоритмы: корректность, граничные случаи, некорректный ввод, экспорт в DOT); настроил измерение покрытия JaCoCo с генерацией HTML-отчёта. 
- Автоматизировал сборку и проверки через Makefile: кросс-платформенная сборка (Windows/Linux) в три JAR (библиотеки + приложение), запуск тестов, отчёт по покрытию, контроль стиля Google Java Format через clang-format. 
- Вёл командную разработку в Git (ветки, 11+ коммитов), отвечал за сборку, тесты и рефакторинг алгоритмов.
