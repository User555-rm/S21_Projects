Брокер сообщений (RabbitMQ) + распределённый кэш Redis: 
- Построил event-driven интеграцию: сервис-генератор по таймеру меняет случайный товар (цена/остаток) и публикует событие в RabbitMQ (Topic Exchange → очередь); API-консьюмер применяет изменение в БД, пишет историю и рассылает обновления. 
- Real-time доставка клиентам по WebSocket (`/ws/products`) и SSE (`/sse/products`); написал HTML/JS эхо-клиенты для обоих каналов. 
- Фотографии товаров кэшируются в Redis (TTL 10 мин) с инвалидацией при изменении. 
- Инфраструктура в Docker Compose: postgres + rabbitmq + redis + api + generator с healthcheck-зависимостями.
