Tic-Tac-Toe — REST-сервис (pet-проект, Школа 21):
- Разработал backend на 3-слойной архитектуре (web / domain / datasource) с разделением моделей слоёв и мапперами между ними: 39 классов, ~1700 строк Java.
- Реализовал ИИ-соперника на алгоритме Minimax (рекурсивный перебор позиций) — компьютер непобедим; добавил валидацию доски: ровно один новый ход, свободная клетка, корректная очередь хода.
- Спроектировал REST API из 13 эндпоинтов: регистрация/логин, создание игры в режимах PvE и PvP, список открытых игр, подключение соперника, ход, история игр, таблица лидеров, профиль пользователя.
- Внедрил JWT-аутентификацию: access-токен 30 мин и refresh-токен 30 дней с хранением в БД, ротацией и отзывом; кастомные Authentication/GrantedAuthority для ролей, stateless SecurityFilterChain и фильтр проверки Bearer-токена.
- Настроил схему PostgreSQL (JPA/Hibernate, UUID-ключи): JPQL-запрос истории завершённых игр и native SQL с `FILTER (WHERE ...)` + `UNION ALL` для расчёта win ratio и выборки топ-N игроков.
- Написал SPA-клиент на чистом JS (~570 строк): экраны аутентификации, меню, игры, истории и лидерборда; авто-обновление токена при 401 и polling хода соперника; централизованная обработка ошибок (@RestControllerAdvice, коды 400/401/403/404/409).
